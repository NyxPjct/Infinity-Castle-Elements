INFINITY CASTLE ELEMENTS — INSANITY 0.0.2

INICIAR
1. Abra o Infinity Castle Elements pelo atalho instalado ou pelo executável Portable.
2. O jogo inicia em tela cheia.
3. Não é necessário instalar Node.js, npm ou qualquer servidor manualmente.

MODOS
SINGLEPLAYER
Escolha um elemento e enfrente a campanha de 1000 fases sozinho.

MULTIPLAYER
Campanha online para 2 jogadores. Crie uma sala privada, envie o código ao outro jogador e os dois ficam sincronizados pelo servidor online.

MODO CAOS — NOVO NA 0.0.2
Campanha online para 4 jogadores.
- A sala exige 4 jogadores.
- Terra, Ar, Luz e Escuridão devem estar presentes.
- Não é permitido repetir elemento na mesma sala Caos.
- Cada fase normal possui quatro selos elementais.
- Cada personagem ativa apenas o selo do próprio elemento.
- A saída só é liberada após os quatro selos.
- Chefes usam quatro runas simultâneas.
- Uma morte reinicia a tentativa para todo o grupo.
- O Modo Caos possui save de campanha separado.

ELEMENTOS
Terra 🪨 — resistente a raízes; ESPAÇO = Raízes do Abismo (1,9s, até 2 alvos).
Ar 💨 — rápido; imune a vento; ESPAÇO = Mini Furacão (2,2s, até 2 alvos).
Luz ☀️ — resistente a maldições; ESPAÇO = Coroa Solar (2,8s, até 3 alvos).
Escuridão 🌑 — ignora controles invertidos; ESPAÇO = Fogo Negro (2,6s, até 2 alvos).

MOEDAS E LOJA
Passe fases, derrote inimigos e sobreviva às tentativas para ganhar moedas. A Loja Arcana oferece boosts e cosméticos.

CONTROLES
A/D ou ← → = mover
W ou ↑ = pular
ESPAÇO = habilidade elemental
COOLDOWN DAS HABILIDADES = 5 segundos após o efeito terminar
R = reiniciar fase
ESC = menu de pausa
F11 = alternar tela cheia

SALVAR
O singleplayer, multiplayer e Modo Caos possuem progresso persistente no desktop. Os saves são mantidos durante atualizações do jogo.

ATUALIZAÇÕES
A versão instalada verifica novas versões automaticamente pelo GitHub Releases. Quando houver uma atualização, o jogo mostra um aviso no menu e em Configurações.

IMPORTANTE
A dificuldade é troll e brutal, mas as pegadinhas são determinísticas: morrer deve revelar uma regra, não depender apenas de sorte.
