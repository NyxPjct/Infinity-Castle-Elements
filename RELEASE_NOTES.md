# Infinity Castle Elements — INSANITY 0.0.7

## Visual Experience Update

A 0.0.7 leva o polimento visual do Infinity Castle Elements para a interface e para o momento a momento do gameplay, mantendo a física, as hitboxes e a estrutura das 1000 fases.

### ✦ Novo
- HUD dark-fantasy redesenhada com progresso visual da torre.
- Indicador circular de duração e recarga do poder elemental.
- Central de **Atualizações** própria no menu principal.
- Histórico de versões e tela de “O que há de novo” dentro do jogo.
- Tela de boas-vindas após uma atualização concluída.
- Sistema versionado de migração de saves.
- Instalação imediata ou opção **Instalar ao sair** no desktop.
- Backup automático dos saves e configurações antes de instalar.
- Download retomável quando a conexão é interrompida.
- Verificação SHA-256 dos arquivos oficiais quando o GitHub fornece o digest.
- Atualização automática segura da edição Portable após fechar o jogo.

### ◈ Visual
- Câmera dinâmica durante velocidade, perseguições, mortes e bosses.
- VFX reforçados para Terra, Ar, Luz e Escuridão.
- Sombras em personagens, jogadores remotos, inimigos e guardiões.
- Inimigos com variações visuais por região.
- Morte cinematográfica com dessaturação, vinheta, zoom e glitches.
- Entrada cinematográfica dos bosses.
- Rank de fase animado.
- Menu principal reage ao progresso salvo.
- Pós-processamento e corrupção visual nas regiões finais.
- Tratamento visual especial para a fase 1000.
- Aura Elemental deixa trilha durante movimento rápido.
- Salas secretas ganharam fragmento flutuante e brilho próprio.

### ⚡ Multiplayer
- O multiplayer passa a usar uma **versão de protocolo independente da versão do jogo**.
- Clientes incompatíveis recebem aviso de atualização em vez de entrarem em salas quebradas.
- O Singleplayer continua disponível quando apenas o protocolo online exige atualização.
- Multiplayer 2P e Modo Caos 4P continuam com armadilhas sincronizadas e progresso compartilhado.

### 🔧 Atualizações e segurança
- A opção de atualização foi removida das Configurações e ganhou uma área própria no menu.
- Quando existe uma versão nova, a tela aparece automaticamente uma vez e mostra as novidades.
- Downloads podem continuar em segundo plano enquanto o jogador volta ao jogo.
- Downloads parciais podem ser retomados.
- O instalador cria backup local antes de aplicar a nova versão.
- A edição Portable é substituída com cópia de segurança do executável anterior.
- Web usa atualização do service worker e recarregamento.
- Android direciona para o APK oficial da release.
- Releases podem ser marcadas como obrigatórias para compatibilidade online.

### ✅ Compatibilidade
- 1000 fases preservadas.
- Singleplayer preservado.
- Multiplayer 2P preservado.
- Modo Caos 4P preservado.
- Saves antigos são migrados para o schema atual.
- Character Visual Overhaul e Castle Visual Overhaul da 0.0.6 continuam integrados.
