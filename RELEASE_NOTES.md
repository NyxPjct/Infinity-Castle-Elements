# Infinity Castle Elements — INSANITY 0.0.8

## In-game Language Update

Changing **Settings → Language** now updates the game interface immediately, including menus, element selection, settings, the HUD, shop, achievements, relics, lore, multiplayer room messages, overlays, illustration labels, and canvas text.

- All 20 language options have complete local text catalogs.
- Brazilian Portuguese remains the default.
- Language preferences are saved on the device.
- Translations work offline with no external translation service.
- Player names, room codes, version numbers, and published release notes keep their original content.
- Arabic uses right-to-left interface text.
- Campaign saves and multiplayer protocol compatibility are preserved.
- Fixed the scope of the desktop post-update welcome message.
- Added localization checks to the audit, Windows, and Android workflows.

English copy and core labels were reviewed. Some translations were prepared automatically and can be refined over time.

## Validation

Validated all 20 language catalogs, placeholder preservation, dynamic text, canvas rendering, repeated switching, saved preferences, and offline gameplay. The existing 1,000-level audit and multiplayer / Chaos integration tests also pass.
